# Plain-language interface text

- Short sentences. Aim for under 14 words.
- Active voice. Speak to the user as "you".
- Lead with the action: "Pick a topic", not "Topics can be picked here".
- Buttons are verbs: "Start", "Next", "Approve".
- Errors: what happened, then what to do. "No connection. Check your network and try again."
- No jargon, no blame, no exclamation marks in errors.
- Numbers as digits: "50 questions".
- Same word for the same thing everywhere.
