How it works

Trivia 50 is a web app you can install on your phone. A team of AI agents helps build it, and a person approves every change.

Playing a round

  1. You pick a topic. The topic list comes from Open Trivia DB and is saved for a day.
  2. Your browser asks Open Trivia DB for up to 50 questions. No server of ours sits in between.
  3. Multiple-choice answers are shuffled fairly. True or False always shows True first.
  4. Each correct answer scores 1 point. Your streak grows with each correct answer in a row.
  5. At the end you see your score, a review of every question, and your best streak.
  6. Scores stay on this device only. Nothing is sent anywhere.

Open Trivia DB allows 1 request every 5 seconds. If it is busy, the app waits and tries again.

Installing and offline use

  • On Android, tap Install in the header, or use the browser menu.
  • On iPhone, tap Share, then Add to Home Screen.
  • A service worker saves the app, so it opens without a connection. New questions still need one.

The Agent Console

The Agents page lists the 12 agents that build this app. Each has a name, a model and its own reference notes.

  1. An admin signs in with Supabase: email and password, or Google.
  2. Only accounts with the super_admin role can open the console. The server checks this on every request.
  3. The admin chats with an agent. A Netlify Function sends the chat to Claude with that agent's own instructions and notes.
  4. An agent can propose a code change. The console shows the full diff.
  5. Nothing is written until the admin clicks Approve and confirms.
  6. Approve makes one commit to main on GitHub. Netlify sees the commit and deploys the new version.

Safety rules

  • API keys live only in Netlify Functions. Your browser never sees them.
  • Agents cannot change server code, settings, agent files, dependencies or the service worker.
  • A proposal goes stale if the files changed after it was made. A second Approve on the same proposal is blocked.
