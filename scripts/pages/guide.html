Setup and deploy guide

Follow these steps to run Trivia 50 on your own Netlify site. Allow about 45 minutes.

1. Before you start

  • A GitHub account with a copy of the repo: isaacbredy27-cloud/AgentTeam2.
  • A free Netlify account.
  • A free Supabase account.
  • A Claude API key from the Claude Console.
  • Node.js 22 or newer, if you want to run it on your computer.

The trivia game works without any of the keys. The keys are only for the Agents page.

2. Run it on your computer

npm install
npm run build
npm run preview:local

Open http://127.0.0.1:8888. This local server uses fake sign-in, fake Claude and fake GitHub. Sign in on the Agents page as admin@example.test with password admin-pass.

To test against real services, use the Netlify CLI with a git-ignored .env file:

npx netlify-cli dev

3. Set up Supabase sign-in

  1. Create a Supabase project. Copy the Project URL and the anon public key from Project Settings, API. Both are public values.
  2. Go to Authentication, Sign In / Providers. Keep Email on.
  3. Optional but advised: turn off Allow new users to sign up. Add admins by invite instead.
  4. Go to Authentication, URL Configuration. Set Site URL to your Netlify URL, for example https://your-site.netlify.app.
  5. Add these Redirect URLs: https://your-site.netlify.app/agents/ and, for local work, http://localhost:8888/agents/.

Turn on Continue with Google

  1. In Google Cloud Console, open APIs and Services, Credentials. Create an OAuth client ID of type Web application.
  2. Under Authorized JavaScript origins, add your Netlify URL.
  3. Under Authorized redirect URIs, add https://<project-ref>.supabase.co/auth/v1/callback. Supabase shows this exact URL on its Google provider page.
  4. Copy the client ID and secret into Supabase, Authentication, Sign In / Providers, Google. Save.

Make someone a super_admin

The role lives in app_metadata. Users cannot change it themselves. Run this in the Supabase SQL Editor after the person has signed in once:

update auth.users
set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb)
                        || '{"role":"super_admin"}'::jsonb
where email = 'admin@your-domain.com';

To remove the role:

update auth.users
set raw_app_meta_data = raw_app_meta_data - 'role'
where email = 'admin@your-domain.com';

The server checks the role on every request, so the change applies at once.

4. Create the GitHub token

  1. Open GitHub, Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Resource owner: the account that owns the repo. Repository access: Only select repositories, then pick this repo.
  3. Permissions: Contents: Read and write. Nothing else. Metadata read comes with it.
  4. Expiration: 90 days or less. Put a reminder in your calendar to renew it.

5. Get the Claude API key

  1. Create a key in the Claude Console.
  2. Set a monthly spend limit there. Each chat turn uses the agent's own model.

6. Deploy on Netlify

  1. In Netlify, choose Add new project, then Import an existing project, then pick the repo.
  2. Netlify reads netlify.toml. Build command: npm run build. Publish directory: dist.
  3. Open Project configuration, Environment variables. Add the variables below.
  4. Deploy. Every push to main deploys again, including commits from Approve.
NameScopeContextType
SUPABASE_URLFunctionsAllPublic
SUPABASE_ANON_KEYFunctionsAllPublic
ANTHROPIC_API_KEYFunctionsProduction onlySecret
GITHUB_TOKENFunctionsProduction onlySecret
GITHUB_OWNERFunctionsAllPublic
GITHUB_REPOFunctionsAllPublic
GITHUB_BRANCHFunctionsAllPublic, default main

Mark the two secrets as secret in Netlify. Deploy Previews then cannot spend money or push commits.

7. Check the deploy

  1. Open the site on your phone. Pick a topic and answer one question.
  2. Install it. On Android tap Install. On iPhone tap Share, then Add to Home Screen.
  3. Open the Agents page. Sign in as your super_admin. Check the agent list loads.
  4. Sign in as a normal user. Check the console stays hidden.
  5. Watch the function logs in Netlify after the first chat.

8. If a deploy breaks

  1. In Netlify, open Deploys. Pick the last good deploy and click Publish deploy.
  2. Then fix forward: revert the bad commit on GitHub and push.
