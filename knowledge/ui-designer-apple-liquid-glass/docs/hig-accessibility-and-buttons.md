# Apple HIG: Accessibility and Buttons (visual rules)

Sources (read 2026-11-25):
- https://developer.apple.com/design/human-interface-guidelines/accessibility
- https://developer.apple.com/design/human-interface-guidelines/buttons

## Sizes (iOS, iPadOS)
| | Default | Minimum |
| --- | --- | --- |
| Control size | 44×44 pt | 28×28 pt |
| Text size | 17 pt | 11 pt |
Buttons: "a hit region of at least 44x44 pt".

## Contrast (HIG table)
| Text size | Weight | Minimum ratio |
| --- | --- | --- |
| Up to 17 pt | All | 4.5:1 |
| 18 pt | All | 3:1 |
| All | Bold | 3:1 |

## Other rules
- Let people enlarge text "by at least 200 percent".
- "Convey information with more than color alone." Red-green and blue-orange pairs are hard for colour-blind people.
- Reduce Motion: fewer automatic animations; replace movement with fades; avoid animating into and out of blurs.
- Buttons: one or two prominent buttons per view. "Use style — not size — to visually distinguish the preferred choice."
- Destructive actions use the system red and never the primary role.
